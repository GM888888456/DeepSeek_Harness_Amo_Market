## 1.4.2（现实价格引擎：新发地菜价 + 外卖派生）

- 新增 `pricing.py`：每天 06:30 拉新发地公开批发均价；周末静默；失败不重试，用昨日缓存 ±3%；22:00–06:00 菜市场关门。

- 城市系数读 `plugin_data/Astrbot_Amo_Marketplace/city_food_index.json`，公开城市食品指数填充前按 1.0，不编价格。
- 30 条测试通过。
